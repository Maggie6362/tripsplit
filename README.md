# TripSplit 旅帳通｜焦糖奶茶版

將 ZIP 完整解壓縮後，用瀏覽器開啟 `index.html` 即可試用。樣式、3D 黏土圖示與統計圖表均隨附，可離線開啟。

- **首頁**可切換全部天數或單日，查看總支出、分攤人數、每人應付與最近紀錄，也可增刪天數。
- **記帳**可選日期與支出分類，輸入金額、品項及付款人。
- **統計**呈現所選範圍的分類支出，**明細**可依分類篩選與刪除紀錄。
- **LINE 分享**可產生結算報告，複製後貼到 LINE。

## 更新既有網站

將 `index.html`、`assets/` 和 `icons/` 一起部署至原本的網站網址。此版本沿用 `tripsplit_multi_data`，使用同一瀏覽器與同一網站來源即可讀取原有資料。直接開啟解壓縮後的本機檔案或改用其他網址時，瀏覽器會使用該位置的儲存資料。

iPhone 可在 Safari 開啟部署網址，選擇「分享」→「加入主畫面」。

## 維護樣式

修改 HTML 的工具類別後，請用 Tailwind CSS 3.4.17 重新產生 `assets/utilities.css`。輸入樣式包含 `@tailwind base;` 與 `@tailwind utilities;`，編譯時將 `index.html` 設為內容來源。
