# TripSplit 旅帳通 - 日系手帳・多日旅行分帳 Web APP

專為 iPhone 與行動裝置打造的高質感旅行手帳記帳與分帳應用程式。本版本全新套用 **UI-03 日系留白手帳風為主、UI-02 Bento 便當格為輔、UI-01 3D 黏土療癒風圖示** 複合式設計系統。

## 🌟 核心特色
1. **複合式手帳美學設計**：UI-03 柔白紙感底色（`#FAF6ED`）與和紙膠帶標籤、UI-02 Bento 規整便當格資訊架構、UI-01 霧面 3D 黏土圓潤圖示與觸控按鈕。
2. **大字體舒適閱讀規範**：內文固定 16–18px、標題 24–30px、總額大數字達 32px，文字對比符合無障礙可讀標準。
3. **iPhone 原生觸控適配**：所有點擊目標皆達 44×44px 觸控熱區、Safe Area 瀏海與底部橫條留白、支援減少動態偏好。
2. **多日行程分組（Day 1 ~ Day N）**：支援隨意增加天數、各日小計徽章、全行程與單日視角即時切換。
3. **即時自動分帳**：自選旅伴人數、每人應付金額連動計算，支援四捨五入、無條件進位（免找零）。
4. **日式手繪質感桌面圖示**：內建 iOS 規範的 180x180 PNG 高清圖示（焦糖牛皮錢包與飛行軌跡），加入 iPhone 主畫面即可體驗原生 App 質感。
5. **LINE 一鍵請款結算報告**：格式化整理總額、每人應付與逐日明細，一鍵複製發送至群組。
6. **本機離線保存 (LocalStorage)**：免登入、無網路也能記帳，重新整理不遺失資料。

## 🚀 部署教學
1. 將本專案中的 `index.html` 上傳至 GitHub 儲存庫（如 `tripsplit`）。
2. 在 GitHub 儲存庫的 **Settings > Pages** 中，將 Branch 設為 `main` (或 `master`) 並點擊 Save。
3. 取得專屬網址後，使用 iPhone Safari 開啟，點擊下方「分享」按鈕 ➜「加入主畫面」即可。
